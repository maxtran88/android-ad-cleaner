## How to read them

- 🔴 Turn off　🟢 Keep　⚠️ Note
- "Path" is the tap order starting from the home screen.
- If your UI does not match the checklist: the system version differs. Search for the switch name in the search box at the top of the settings page; most can be found that way.

## Three things every brand must do

1. **System ad switches**: search "ads" in Settings.
2. **Ad tracking / OAID**: search "ad tracking" or "device identifiers" in Settings, and turn off every app's switch.
3. **Marketing notifications**: in Notification management, tap into each app and turn off channels named with "marketing", "activity", "offers", "recommendations", or "news"; keep order, delivery, update, and chat channels.
   - Some vivo pages only have an app-level master switch and cannot be safely turned off per channel; the current tool skips them, see the [vivo checklist](vivo-OriginOS.md).
